# WorkLens

### Make remote work visible and verifiable.

WorkLens is a smart remote work management platform designed to help managers and employees manage tasks, submit work, verify deliverables, review progress, and collaborate through live meetings.

The platform combines task management, AI-assisted submission verification, manager review, work progress tracking, and live Jitsi meetings into one workflow.

---

## 🚀 Features

- 🔐 Authentication and role-based access
- 🏢 Organization-based workspace
- 👥 Manager and employee dashboards
- 📋 Task creation and assignment
- ⏰ Task deadlines
- 📤 File-based work submission
- 🤖 AI-assisted work verification
- 👨‍💼 Manager review and feedback
- ✅ Approve / Reject / Request Changes
- 🔄 Work resubmission
- 📊 Progress dashboard
- 🧾 Work Evidence Timeline
- 🎥 Live work review using Jitsi
- 🔒 Organization and employee-level access control
- 📚 Work submission history
